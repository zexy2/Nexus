# Changelog

Notable changes to Nexus. Full notes are on the [releases page](https://github.com/zexy2/Nexus/releases).

## [0.1.0] - 2026-11-25

First public release of the workspace running at https://nexus.zekiakgul.dev.

- Plan edits become proposed task changes; nothing reaches the Kanban board without approval
- Durable approval workflows on Temporal and PostgreSQL that apply approved GitHub and Linear updates with bounded retries
- Signature-verified webhooks, per-user quotas and versioned task briefs over MCP
- Unit and end-to-end tests in CI on every pull request
